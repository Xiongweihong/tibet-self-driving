## 📲 iOS / iPhone 最佳使用方式（添加到主屏幕）

1. 在 iPhone Safari 浏览器中打开上方网址；
2. 点击 Safari 底部中央的**「分享」**按钮（带有向上箭头的方框）；
3. 向上轻滑菜单，选择**「添加到主屏幕」**（Add to Home Screen）；
4. 手机桌面上即可生成独立的原生 App 图标，点击全屏沉浸运行，无地址栏干扰；
5. 行车中通过蓝牙/无线 CarPlay 连车机，特级警笛音效与高危避险语音将直接通过车载音响高保真播报！

## 🌟 核心功能特性

1. **48 行政区全息微气候监测**：直连 Open-Meteo 开源气象 API，提供实时气温、温差、风速、海拔标称数据及离线物理微气候模型。
2. **12 大历史重大地灾重点监控舱**：海通沟、通麦天险、怒江72拐、白格堰塞湖、S211千仞绝壁等历史险情全息档案。
3. **分级提级预警与特级警报音**：设定红色特级、橙色高危、黄色中度分级标准；高危路段触发双音频锯齿波警笛音效。
4. **车载级免视线交互（Web Speech API）**：一键全线地灾巡航播报，自动置顶播报高危路段防御要领。
5. **一键遇险 SOS 报案**：自动生成包含经纬度、标称海拔、就近垭口与气象的标准化遇险求救报文，配备 122/12122 专线。
